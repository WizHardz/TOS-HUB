Chat overlay preview

Change the look with Overlay settings (or hover the preview and click ⚙), then press Save in that menu. Turn on Demo mode there to see fake chatters.

Chat on my screen only you see it

A see-through chat window that floats over your game so you can read chat while you play. Your mouse clicks go straight through it, and it's hidden from OBS so it never shows on stream.

Alert sound (just for you)

So chat can't hear it, play it through a device OBS doesn't record, like your headphones or a separate output. In OBS, Settings → Audio shows which device Desktop Audio records: pick a different one here. On the RØDECaster, pick a spare virtual output (like “B”) and take its fader out of the USB 1 routing (Duo: Settings → Outputs → Routing). Then check it with “Can the stream hear my alert?” in Stream view.

Ctrl+Shift+C shows or hides it while you're in a game, and Ctrl+Shift+L lets you move it. It shows over games in borderless or windowed mode. In exclusive fullscreen Windows draws the game over everything, so switch the game to borderless.

Send to OBS

“Update” loads your saved overlay settings into that OBS source. “Create” adds a new WizHardz Chat source to the scene you're on. Do this again whenever you change the look.
