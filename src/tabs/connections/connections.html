OBS connection

How to connect OBS (one-time setup)
  1. Open OBS Studio (version 28 or newer has this built in).
  2. In OBS's top menu, click Tools → WebSocket Server Settings.
  3. Tick Enable WebSocket server. Leave the port as 4455 and keep Enable Authentication ticked.
  4. Click Show Connect Info, then the Copy button next to Server Password.
  5. Back here, paste it into Password, tick Remember and click Connect. You can click OK in OBS to close its window.

OBS on a different computer? Put the Server IP from Show Connect Info into Host instead of localhost.

How to set it up in VoiceAttack (2 minutes)
  1. Open VoiceAttack, click the pencil (Edit profile), then New Command.
  2. In When I say, type what you'll say (e.g. fire, become an orange, clear drawing).
  3. Click Other ▸ Windows ▸ Run an Application.
  4. Paste the Application and With these parameters lines from above (Copy buttons), and set the window to Hidden so nothing pops up.
  5. Click OK, OK, Done. Say it: TOS HUB does it.
